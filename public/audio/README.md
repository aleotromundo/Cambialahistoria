# Bundled replacement audio

This directory contains a generated replacement audio pack for local and standalone builds. The WAV files were generated by `tools/build-generated-audio.py` and are not the private production recordings from the original game.

The pack is provided as original procedural audio for this repository. The manifest maps the sound ids from `data/audio.json` to the bundled files. To use an authorised production asset server instead, set `VITE_ASSET_BASE` to its URL before starting the dev server.
